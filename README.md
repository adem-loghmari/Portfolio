# Portfolio

Personal site for Adam Hmida Loghmari. React 18, TypeScript and MUI, built with Vite.

```sh
npm install
npm run dev     # local dev server
npm run build   # production build in dist/, including a 404.html copy of the app shell
```

Project and experience content lives in `src/components/Projects.tsx` and `src/components/Experience.tsx`. The contact address is in `src/lib/contact.ts`.
